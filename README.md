# معرض أعمالي

موقع شخصي بسيط لعرض برامجي ومشاريعي. يدعم العربية (RTL)، الوضع الليلي، تصفية المشاريع حسب النوع، والبحث.

## تعديل المحتوى

كل البيانات في ملف `data.js`:

- `PROFILE`: الاسم، المسمى، النبذة، الصورة، البريد، الروابط، المهارات.
- `PROJECTS`: قائمة المشاريع. لكل مشروع: `title`, `description`, `category`, `tags`, `image`, `demo`, `source`, `featured`.

أزرار التصفية والإحصائيات تُنشأ تلقائياً من المشاريع.

## التشغيل

افتح `index.html` في المتصفح مباشرة، أو:

```bash
python3 -m http.server 8000
```

## النشر على GitHub Pages

من إعدادات المستودع: **Settings → Pages** ثم اختر الفرع والمجلد الجذر `/`.
