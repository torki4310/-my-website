# معرض أعمالي

موقع شخصي بسيط لعرض برامجي ومشاريعي. خلفية شبكة متحركة، ومعرض مشاريع ثلاثي الأبعاد على شكل دائرة تدور (سحب، أسهم، نقر للاختيار)، وتصفية حسب النوع.

## تعديل المحتوى

كل البيانات في ملف `data.js`:

- `PROFILE`: الاسم، المسمى، النبذة، صورة الخلفية (اختيارية)، البريد، الروابط، المهارات.
- `PROJECTS`: قائمة المشاريع. لكل مشروع: `title`, `description`, `category`, `tags`, `image`, `demo`, `source`, `featured`.

أزرار التصفية والإحصائيات تُنشأ تلقائياً من المشاريع.

## التشغيل

افتح `index.html` في المتصفح مباشرة، أو:

```bash
python3 -m http.server 8000
```

## النشر على GitHub Pages

من إعدادات المستودع: **Settings → Pages** ثم اختر الفرع والمجلد الجذر `/`.

## ملف شركتي (تطبيق منفصل)

مجلد [`malaf/`](malaf/README.md) يحتوي تطبيق «ملف شركتي» لإنشاء ملفات تعريفية للشركات بمساعدة الذكاء الاصطناعي وتصديرها PDF. يحتاج خادم Node.js ولا يعمل على GitHub Pages. التفاصيل وتعليمات التشغيل في `malaf/README.md`.

## منتجع مرسى اللؤلؤ (صفحة سياحية)

مجلد [`resort/`](resort/index.html) يحتوي صفحة لموقع منتجع فاخر، خلفيتها فيديو بحر هادئ (`sea.mp4`) تم توليده بالذكاء الاصطناعي. افتح `resort/index.html` مباشرة، ونموذج الحجز فيها للعرض فقط ولا يرسل بيانات.
