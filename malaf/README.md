# ملف شركتي

موقع عربي لإنشاء ملفات تعريفية (Company Profile) احترافية للشركات. يُدخل المستخدم معلومات شركته وشعارها وصور أعمالها، ويساعده الذكاء الاصطناعي على صياغة المحتوى، ثم يختار القالب ويعدّل النتيجة وينزّل ملف PDF.

## التشغيل

المتطلبات: Node.js 20 أو أحدث.

```bash
cd malaf
npm install
npx playwright install chromium   # مرة واحدة: المتصفح المستخدم لتصدير PDF
cp .env.example .env              # ثم املأ SESSION_SECRET، و ANTHROPIC_API_KEY إن توفر
npm start                         # http://localhost:3000
```

- بدون `ANTHROPIC_API_KEY` يعمل كل شيء في **وضع تجريبي** معلن في الواجهة: يُبنى الملف من نصوص المستخدم كما هي مع عناوين جاهزة، بلا تحسين صياغة ولا ترجمة ولا إعادة صياغة. لا يُقدَّم هذا على أنه توليد ذكي.
- مع المفتاح: يُستدعى Claude من الخادم فقط (`server/ai.js`). المفتاح لا يصل للمتصفح ولا يُحفظ في المستودع.

### الاختبارات

```bash
npm test        # اختبارات وحدات سريعة (تنقية المدخلات، الحمايات، القالب)
npm run e2e     # الرحلة كاملة في متصفح حقيقي + فحص ملفات PDF (يحتاج poppler-utils لفحص النص والصور)
```

اختبار `e2e` يشغّل الخادم بنفسه ويستخدم شركات **افتراضية معلنة** وصورًا اختبارية مكتوب عليها TEST IMAGE. مسار الذكاء الاصطناعي يُختبر عبر خادم Anthropic وهمي محلي (`test/mock-anthropic.js`) يتعمّد «اختلاق» رقم وعبارة تفضيل ومشروع غير موجود للتحقق من أن الحمايات تلتقطها. المخرجات (PDF وصور صفحاتها ولقطات الواجهة) في `test/output/`.

## قرارات تقنية

- **الخادم:** Node.js + Express، بلا قاعدة بيانات: كل مشروع ملف JSON ومجلد صور تحت `DATA_DIR/users/<معرّف المستخدم>/projects/<المشروع>/`.
- **الواجهة:** HTML/CSS/JavaScript بلا أطر عمل ولا خطوة بناء (مثل باقي المستودع). كل نص من المستخدم يُدرج عبر `textContent`.
- **PDF:** نفس قالب HTML للمعاينة والتصدير، يُطبع عبر Chromium (Playwright). هذا يعطي تشكيلًا عربيًا صحيحًا، وخطًا مضمّنًا، ونصًا قابلًا للتحديد والنسخ، وصفحات إضافية تلقائيًا للنصوص الطويلة.
- **الخط:** Readex Pro (رخصة SIL OFL) عربي ولاتيني. اختير بعد مقارنة عملية: خطوط IBM Plex Arabic و Cairo و Tajawal تُنتج نصًا منسوخًا بحروف مقلوبة لبعض الروابط، وخطوط Noto العربية تفقد النص كليًا عند النسخ. بقيت مشكلة رباط «لا» (يُنسخ «ال» معكوسًا في قارئات PDF)، وعولجت في `server/pdffix.js`.
- **الصور:** تُقبل PNG و JPG و WebP فقط، ويُتحقق من نوعها من محتواها لا من امتدادها، وتُحفظ بأسماء عشوائية. تُعرض في صفوف متناسقة بنسبها الأصلية دون قص أو تشويه.
- **الذكاء الاصطناعي:** `claude-opus-5-5` عبر `@anthropic-ai/sdk` مع مخرجات JSON مقيدة بمخطط (structured outputs)، وبث الاستجابة، و`fallbacks: "default"` لإعادة المحاولة على نموذج بديل إن رُفض الطلب. القوالب ثابتة؛ النموذج يكتب المحتوى فقط.

## حماية البيانات

- **العزل:** كل متصفح يحصل على معرّف عشوائي داخل كعكة `HttpOnly` موقّعة (HMAC). كل طلب يتحقق أن المشروع والملف ملك صاحب الطلب؛ غير ذلك يعيد 404.
- **الملفات ليست عامة:** لا يوجد مسار ثابت للصور المرفوعة؛ تُقدَّم فقط عبر واجهة تتحقق من المالك.
- **CSRF:** الطلبات المعدِّلة تتطلب ترويسة مخصصة لا تستطيع النماذج الخارجية إرسالها، مع `SameSite=Lax`.
- **الحدود:** حجم الصورة (5 ميغابايت)، عدد الصور لكل مشروع، عدد المشاريع لكل مستخدم، وعدد طلبات التوليد (20/ساعة و 60/يوم) وتصدير PDF لكل مستخدم، وحد عام لكل عنوان IP.
- **ترويسات أمان:** CSP صارمة، ومنع تضمين الصفحات خارجيًا، وطباعة PDF بلا JavaScript وبلا أي طلبات شبكة.

**قيد مهم:** الهوية مرتبطة بالمتصفح. مسح ملفات تعريف الارتباط، أو استخدام جهاز آخر، يفقد المستخدم الوصول لمسوداته (تبقى على الخادم). الخطوة التالية المقترحة: تسجيل دخول بالبريد الإلكتروني.

## ما يحتاج إعدادًا خارجيًا

1. **مفتاح Anthropic API** (`ANTHROPIC_API_KEY`) لتفعيل الصياغة والترجمة وإعادة الصياغة. التكلفة تُحتسب على حسابك لدى Anthropic.
2. **SESSION_SECRET** ثابت في الإنتاج.
3. **استضافة** تسمح بتشغيل Chromium (خادم VPS أو حاوية؛ الاستضافات «بلا خادم» غالبًا لا تناسب)، مع مجلد بيانات دائم و HTTPS (ثم `COOKIE_SECURE=true`).
4. **نسخ احتياطي** لمجلد `DATA_DIR`.
5. حدود الطلبات محفوظة في الذاكرة: تكفي لخادم واحد؛ عند التوسع لعدة خوادم تحتاج مخزنًا مشتركًا (Redis مثلًا).

```
  index.js     المسارات والتحقق من الملكية والحدود
  ai.js        استدعاء Claude، الوضع التجريبي، إعادة الصياغة، الترجمة
  guard.js     الحمايات: المشاريع المختلقة، الأرقام والادعاءات غير المسندة، النواقص
  render.js    القالبان (HTML/CSS) — نفسهما للمعاينة و PDF
  pdf.js       التصدير عبر Chromium
  pdffix.js    تصحيح نسخ رباط «لا» من PDF
  schema.js    تنقية كل المدخلات
  store.js     التخزين على القرص لكل مستخدم
  auth.js      الهوية المجهولة الموقّعة
  sample.js    الشركة الافتراضية للنموذج
public/        الصفحة الرئيسية والمحرر
test/          اختبارات الوحدات والرحلة الكاملة وخادم Anthropic الوهمي
```
